1. Preview the results

Open the synthetic example or the public HA example. No installation is needed to view these reports. Keep this folder together so its links work.

The synthetic example has 48 records in four groups of 12. Its mutation counts are 12, 12, and 24. The public HA fixture contains 24 records; source details and expected counts are in example_inputs.

2. Install and run

Follow the installation and testing guide. The installable wheel is in package. Python 3.9 or newer and MAFFT are required; Python dependencies are downloaded during installation. MAFFT is installed separately.

After installation, use flutrees --demo --tree-mode all --open for the included example, or flutrees --gui for desktop file selection. The desktop window requires Python with Tk support.

3. Check an analysis

Release acceptance matrix · Validation scope and evidence

Follow the guide's output checklist, then run a small unaligned protein FASTA with known expected results. Confirm the reference and residue window. The default window is 84–284 inclusive.

FluTrees builds mutation decision trees, not phylogenies. The example datasets are software test fixtures. Check the quality notes and coordinate conventions before interpreting laboratory data.
