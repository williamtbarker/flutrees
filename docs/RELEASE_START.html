2. Install and run

Follow the installation and testing guide. The installable wheel is in package. Python 3.9 or newer and MAFFT are required; Python dependencies are downloaded during installation. MAFFT is installed separately.

Already installed? Activate the environment where you installed FluTrees and enter flutrees --gui. The desktop window requires Python with Tk support. Graphviz is not required for the GUI or its normal figure exports.

  1. On Analysis, click Use included example. In a newly opened window, leave the defaults and the blank Run ID unchanged.
  2. Click Analyze sequences. Check Run log for progress.
  3. When the status says Complete, click Open results, then select the example dataset. Start with its report and workbook.
  4. Open Tree viewer to inspect full or pruned trees. Change width, height, node gaps, or line width, then click Apply layout. Use Whole page to preview the exported page shape.
  5. Use Fit, zoom, and the page buttons to inspect the tree. Save page... exports one displayed page as PDF, SVG, or PNG without rerunning alignment; choose a new filename for the adjusted figure.

The README's Quickstart: GUI Mode explains how to run your own FASTA files, choose analysis settings, adjust figures, and reopen or share results. See the GUI/CLI parameter map for all settings and ranges.

FluTrees builds mutation decision trees, not phylogenies. The example datasets are software test fixtures. Check the quality notes and coordinate conventions before interpreting laboratory data.
